# 🌐 Profesjonalne Portfolio Sieciowe Cisco (Cisco Packet Tracer Labs)

---

## 🇵🇱 Wersja Polska

### O projekcie
Niniejsze repozytorium stanowi kompleksowe portfolio inżynierskie z zakresu sieci komputerowych i teleinformatyki, dokumentujące moje umiejętności w projektowaniu, konfiguracji oraz wdrażaniu zaawansowanych architektur sieciowych w środowisku **Cisco Packet Tracer**. Repozytorium zostało podzielone na dwa etapy edukacyjne: ubiegłoroczne sieci korporacyjne oraz bieżące implementacje zaawansowanych rozwiązań teleinformatycznych.

### Struktura Repozytorium
Repozytorium składa się z dwóch głównych modułów roboczych:
1. **[PART 1 - Enterprise Network]** – laboratoria z zakresu tradycyjnych sieci korporacyjnych (OSPFv2 Multi-Area, Standardowe i Rozszerzone ACL, HSRP, tunelowanie GRE/VPN).
2. **[PART 2 - Advanced ICT Solutions Implementation]** – zaawansowane scenariusze teleinformatyczne.

### Technologie i Stack Technologiczny
- **Symulator:** Cisco Packet Tracer 8.x
- **Urządzenia sieciowe:** Routery Cisco ISR, Przełączniki wielowarstwowe Catalyst, Przełączniki dostępu,...
- **Protokóły i technologie:** VLAN, 802.1Q, EtherChannel (LACP), STP (Rapid PVST+), HSRP, DHCP, OSPFv2, Frame Relay (DLCI), PPP (CHAP), NAT Overload (PAT), GRE Tunnels.
- **Metodologia:** Konfiguracja bazująca na CLI, autorskie schemator, projektowanie podsieci metodą VLSM.

## 🇪🇳 English Version

### About the Project
This repository serves as a comprehensive engineering portfolio in computer networks and teleinformatics, documenting my skills in designing, configuring, and deploying advanced network architectures within **Cisco Packet Tracer**. The repository is organized into two educational phases: last year's enterprise networks and current advanced ICT solution implementations.

### Repository Structure
The repository consists of two primary working modules:
1. **[PART 1 - Enterprise Network]** – laboratory exercises focused on traditional enterprise networking (OSPFv2 Multi-Area, Standard & Extended ACLs, HSRP, GRE/VPN tunneling).
2. **[PART 2 - Advanced ICT Solutions Implementation]** – advanced teleinformatics scenarios.

### Technology Stack
- **Simulator:** Cisco Packet Tracer 8.x
- **Network Hardware:** Cisco ISR Routers , Catalyst Multilayer Switches, Access Switches,...
- **Protocols & Technologies:** VLANs, 802.1Q, EtherChannel (LACP), STP (Rapid PVST+), HSRP, DHCP, OSPFv2, Frame Relay (DLCI), PPP (CHAP), NAT Overload (PAT), GRE Tunnels.
- **Methodology:** CLI-driven configuration, custom IP addressing schemes, VLSM subnetting design.
